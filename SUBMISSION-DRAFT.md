## Project description (submission form)
NEAR Investment Thesis is a live onchain dashboard and a re-runnable valuation
model for NEAR. It pulls usage, fee, TVL, staking and NEAR Intents data from free
public APIs with one command, then values NEAR with three peer-multiple lenses
and a median fair-value band. Users can switch Bear/Base/Bull scenarios or set
every multiple by hand and watch the band, implied price and verdict update. The
thesis, the evidence against it and the data that would falsify it are all on
the page.
